# Welcome to Pacto

## What is Pacto?

**Pacto** is a **decentralized peer-to-peer (P2P) marketplace network** built on top of **Trustless Work**’s escrow infrastructure. It empowers **anyone to become a merchant** and help onboard or offboard users into crypto—without needing to rely on centralized exchanges or regulated on-ramp providers.

Think of it as the **M-Pesa moment for crypto**: enabling the last mile of adoption in a decentralized, open, and accessible way.
