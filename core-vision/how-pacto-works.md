# How Pacto Works

Pacto is a discovery and escrow layer.

1. A user finds a nearby or online merchant through the Pacto network
2. Both agree on terms (e.g., buy USDC for local cash)
3. Onchain Funds are secured in a Trustless Work smart escrow while the fiat transaction happens.&#x20;
4. Once both parties confirm the fiat transaction, the escrow releases funds

#### Key Features:

* **Role-Based Escrow**: Each user has a defined role (e.g., buyer, seller, verifier)
* **Non-Custodial**: Neither Pacto nor Trustless Work holds funds
* **Transparent**: Every transaction is on-chain and verifiable
