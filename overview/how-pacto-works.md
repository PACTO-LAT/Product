# How Pacto Works

Pacto operates as a decentralized discovery layer for peer-to-peer exchanges. Once a buyer and seller agree on a trade, the transaction is secured through a **Trustless Work smart escrow**.

#### Key Components:

* **Discovery Layer**: Users find merchants or peers offering exchange services.
* **Escrow Automation**: Trustless Work provides programmable smart contracts to handle deposits, approvals, and fund releases.
* **Role Assignment**: Each transaction defines clear roles—Buyer, Seller, Milestone Marker, Approver, Dispute Resolver.
* **Transparent Lifecycle**: Funds are only released when both parties fulfill their conditions.

Neither Pacto nor Trustless Work ever holds funds. Both systems are fully non-custodial.
