# Escrow-Powered Trust

Pacto doesn’t rely on reputation alone — it uses smart escrow contracts to automate and secure transactions.

Escrow flows are:

* **Non-custodial**: No one holds funds on behalf of users
* **Programmable**: Each party’s role is defined (buyer, seller, signer)
* **Transparent**: Funds are released only when predefined actions occur

The escrow contracts are provided by **Trustless Work**, but Pacto controls how they’re used in the context of peer-to-peer trade.

This removes the need for centralized arbitration or pre-existing trust between users.
